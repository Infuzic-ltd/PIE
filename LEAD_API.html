Lead Intake API

Register a new lead into the CRM from outside systems — a website form, a WhatsApp bot, a property portal. Every successful call is automatically scored, assigned to an agent, and the agent is notified.

POST /api/leads/create/

Authentication

Every request must include the shared key in a header. It's set via the LEAD_API_KEY environment variable — treat it like a password.

X-Api-Key: your-key-here
401
{"error": "Invalid or missing API key."} — header absent or doesn't match.

Request

Only full_name and phone are required. Everything else falls back to a sensible default.

Assignment: auto vs. explicit

Most leads have no agent yet, so by default the lead is auto-assigned — round-robin to whichever active agent currently has the fewest leads. If the lead is already assigned on your side — say, it came from an agent's own listing, or a referral routed to a specific agent — pass that agent's phone number in agent_phone instead. It's matched by digits only, so local (0312 2211828) and international (+92 312 2211828) formats both work, and auto-assignment is skipped entirely.

Behavior

Auto-assignment

When agent_phone isn't supplied, the lead goes to whichever active agent currently has the fewest leads — this keeps the workload equal across the team over time. If no active agent exists, assigned_to stays empty.

Explicit assignment

When agent_phone is supplied and matches an active agent, the lead is assigned directly to them and auto-assignment is skipped entirely — this is how an already-assigned lead is registered.

Lead scoring

A starter rule based on what's known about the lead at creation time:

  • +1 for each of: budget set, interested_in set, area_preferences set, bedrooms/bathrooms set
  • Score ≥ 2 → Warm, score ≥ 5 → Hot, otherwise Cold
  • Later pipeline progress (in the CRM) adds further points — a freshly-created lead only reflects the signals above
Easy to retune once you've seen it run against real data — see Lead.calculate_lead_score() in accounts/models.py.

Notification

If an agent was assigned, they get an in-CRM notification linking straight to the lead, plus a browser push notification if they have push enabled.

Limitations

  • No deduplication — calling this twice with the same phone number creates two separate leads.
  • No rate limiting — the API key is the only gate. Don't expose it publicly.

Examples

# create a lead from a WhatsApp bot handoff
curl -X POST https://your-domain.com/api/leads/create/ \
  -H "Content-Type: application/json" \
  -H "X-Api-Key: YOUR_LEAD_API_KEY" \
  -d '{
    "full_name": "Ali Raza",
    "phone": "03001234567",
    "email": "ali@example.com",
    "source": "whatsapp",
    "lead_type": "buyer",
    "interested_in": ["house", "plot"],
    "area_preferences": "Block A, Block C",
    "budget_min": 5000000,
    "budget_max": 15000000,
    "bedrooms_min": 3,
    "notes": "Wants a corner plot, prefers Block C."
  }'
